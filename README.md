# Track-Rank 🏎️💨

> **Track-Rank** ist eine moderne, installierbare Progressive Web App (PWA) zur präzisen Performance-Messung von Fahrzeugen, Echtzeit-GPS-Geschwindigkeitserfassung und zum Vergleichen von Fahrzeugdaten.

## 📖 Über das Projekt

Track-Rank nutzt die Browser-Geolocations-API in Kombination mit modernen Web-Technologien, um Fahrzeugen performancebezogene Metriken ohne teure Zusatzhardware zur Verfügung zu stellen. Die App liefert hochpräzise Echtzeitdaten direkt auf das Smartphone und eignet sich sowohl für Messungen auf der Strecke als auch für den Vergleich unterschiedlicher Fahrzeugprofile.

---

## ✨ Features & Funktionsumfang

### ⏱️ 1. Echtzeit-Performance-Timing (0–100 km/h)
* **Automatischer Messstart:** Der Timer startet exakt in dem Moment, in dem die GPS-Geschwindigkeit von 0 km/h ansteigt.
* **Präzise Stopp-Erkennung:** Automatische Stoppuhr-Auslösung beim Erreichen der 100-km/h-Marke.
* **Ergebnis-Historie:** Speicherung und Übersicht der gemessenen Zeiten zur späteren Analyse.

### 📍 2. GPS-Tacho & Live-Telemetrie
* **Echtzeit-Geschwindigkeit:** Anzeige der aktuellen Geschwindigkeit in km/h auf Basis hochfrequenter GPS-Updates.
* **Signalgüte-Indikator:** Visualisierung der GPS-Genauigkeit zur Gewährleistung verlässlicher Messdaten.

### 📊 3. Fahrzeug-Vergleich & Rankings ("Street Rank")
* **Fahrzeugdaten-Datenbank / Vergleiche:** Gegenüberstellung von Performance-Metriken verschiedener Fahrzeugmodelle.
* **Ranking-System:** Übersicht und Einordnung von Zeiten und Beschleunigungswerten.

### 📱 4. Progressive Web App (PWA) Capabilities
* **Installierbar:** Lässt sich auf iOS, Android und Desktop direkt als eigenständige App auf dem Homescreen installieren.
* **Offline-Support:** Dank Service Worker funktioniert die Benutzeroberfläche auch bei schwankender Mobilfunkabdeckung.
* **Responsive UI:** Für die einhandgeführte Nutzung im Fahrzeug optimiertes Interface mit klarem, gut ablesbarem Design.

---

## 🛠️ Tech Stack & Architektur

* **Frontend:** HTML5, Modern JavaScript (ES6+)
* **Styling & UI:** Tailwind CSS (Responsive Design, Dark Mode)
* **APIs:** HTML5 Geolocation API, Web Storage API, Service Worker API
* **Hosting & Deployment:** Vercel / Cloudflare DNS & Pages
